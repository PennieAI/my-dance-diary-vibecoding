# My Dance Diary 产品口播

我买了舞蹈年卡以后，遇到一个很具体的问题：课表每天都在看，但我不知道自己到底上了多少节、哪几天偷懒了，也看不到每一次练习有没有真的进步。

所以我用 Vibe Coding 做了这个 My Dance Diary。它不是单纯把纸质课表搬到网页上，而是把“选课、上课、复盘”连成了一条完整的记录。

打开页面，我可以在月视图里快速看哪些天上过课，切到周视图后，再按时间段选择当天真正上的那一节。每次打卡还要给自己打 1 到 5 分：有没有放炮、敢不敢 SOLO、有没有和老师一起跳，都有明确标准。

我还把课程难度和自评分组合成了一个“舞力值”。比如课程难度是 D3，当天状态打 4 分，那这节课的舞力就是 12。这样记录的不只是“我来过”，还有“我今天跳得怎么样”。系统也会根据累计课次，自动计算当前的单节课价，让坚持这件事变得更直观。

这个产品最有意思的地方，是它真的来自一次次对话：我先把课表图片交给 AI，再不断补充规则、调整视觉、发现不好用的地方，然后继续改。Vibe Coding 对我来说，不是一句话生成一个网页，而是把脑子里原本模糊的需求，慢慢打磨成一个自己每天愿意打开的产品。

现在我把去掉个人课表和数据的版本开源了。你只需要替换示例配置，就可以拥有自己的练舞日记。
